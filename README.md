# 🏃 Run Tracker (跑步记录 App)

基于 **Flutter** 构建的高颜值、高性能、**0支出（Zero-Cost / 完全免费开源）** 跑步记录与运动追踪应用。

---

## 🌟 0 支出（Zero Cost）架构说明

本项目严格贯彻 **0 成本** 开发理念，无需任何商业付费服务与云服务器：

1. **地图引擎**：基于 `flutter_map` + **OpenStreetMap (OSM)** 开源瓦片，无需申请高德/Google商业 Key，无需绑定信用卡，零 API 费用。
2. **定位追踪**：基于 `geolocator` 直接调用手机硬件 GPS 与系统底层定位，高精度无限制。
3. **数据存储**：基于本地 `sqflite` (SQLite) 数据库，轨迹点、配速数据全部保存在用户本地，隐私安全且零服务器租用费。
4. **语音播报**：基于 `flutter_tts` 原生系统语音引擎，离线语音播报整公里用时与配速，零在线合成费用。
5. **生态共享**：支持一键导出 **标准 GPX 轨迹文件**，兼容 Strava、Keep、Garmin、Apple 健康等。

---

## 📱 核心功能特性

- **🏃 实时运动仪表盘**
  - 启动前 3-2-1 语音倒计时
  - 实时累计距离（km）、耗时、即时配速、平均配速、能耗（kcal）
  - 动态地图航迹绘制（Polyline 发光轨迹与平滑跟踪）
  - 长按 2 秒防误触结束运动保护
  - 智能 GPS 漂移滤波（过滤低精度点与静止原地漂移）
  - **内置“模拟跑步模式”开关**：无需走出户外，直接在电脑端或模拟器快速预览真实轨迹生成
- **🎙️ 离线语音助教**
  - 运动启动、暂停、继续、结束语音提醒
  - 每 1 公里自动播报阶段用时与配速（如：“已完成 1 公里，本公里用时 5 分 15 秒”）
- **📊 跑步战报与历史分析**
  - 精致战报复盘卡片（全览整条运动轨迹线与起终点）
  - 每公里分段柱状图（Kilometer Splits，基于 `fl_chart`）
  - 历史跑步记录瀑布流
  - 累计总跑量、总运动时长、PB最长单次距离展示
  - 近 7 日跑量走势柱状图

## 🚀 快速运行与调试

### 1. 进入项目目录
```bash
cd run_tracker
```

### 2. 启动运行
- **在连接的 Android 手机 / 模拟器上运行**：
  ```bash
  flutter run
  ```
- **在 Chrome 浏览器中预览运行**：
  ```bash
  flutter run -d chrome
  ```

> 💡 **提示**：在电脑端或室内体验时，点击首页右上角的 **「模拟模式」**，点击 **GO** 即可看到自动模拟公园跑步路线的完整实时动画、分段配速和战报生成！
